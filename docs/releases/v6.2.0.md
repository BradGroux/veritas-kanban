Veritas Kanban 6.2.0 improves the everyday work of changing settings, navigating a board, and using the macOS application.

Release source for 6.2.0. Signing, distribution and publication evidence are recorded in the [release evidence packet](https://github.com/BradGroux/veritas-kanban/blob/v6.2.0/docs/V6-RC-EVIDENCE-PACKET.md).

## What changed

Settings keeps pending edits when you change sections or close the window. Failed saves remain available for retry, and importing a settings file reports success after the server saves it. On macOS, Settings opens in one reusable native window, so the board stays usable alongside it. Quitting waits for pending settings saves and asks you to return to Settings if a save fails.

Settings search takes you to the relevant section and control. Appearance offers System, Light and Dark while retaining existing explicit preferences. On a phone, search and the active-filter count stay visible while secondary filters use a compact disclosure.

Native New Task and Settings commands reach the application. Standard macOS Close, Hide, Quit, zoom and full-screen commands are available. Window restoration accounts for changed displays, and title-bar double-click follows the system preference. Narrowing a window closes background chat without dismissing the task above it.

Keyboard navigation follows the visible board order and brings selected tasks into view. Shortcut help follows the configured columns. Modified commands and IME composition keep their normal behavior. Primary actions, selected filters and code labels have corrected contrast, and browser setup no longer presents unavailable desktop diagnostics.

Large boards load compact card records and window long columns. Full descriptions and run details load when you open a task; search still checks the complete description. Task reads revalidate after changes, and moving a task remains valid in columns containing more than 1,000 cards. Notification updates change the affected SQLite rows, while file-backed notification storage preserves recoverable data on write failures.

CLI and MCP commands reject empty or ambiguous task identifiers, enforce request deadlines, and preserve actionable API error information. Use a full task ID when a suffix matches more than one task.

## Security fixes

Version 6.2.0 corrects permission matching for case variants, prevents generic task edits from replacing managed run authority, bounds routing preview work, and rejects redirected desktop connection-verification requests. Upgrade all maintained packages together. The security advisories record the affected 6.1.7 release, remediation, and validation limits.

## Install

Use the signed and notarized macOS arm64 DMG or ZIP in the release Assets section. The supported Homebrew cask is `bradgroux/tap/veritas-kanban`. Linux and Windows remain verification previews.

## Compatibility and upgrade

The public REST API remains `v1`. All maintained packages must use 6.2.0 together. Existing full-task and summary APIs remain compatible, and this release adds no database migration. Retain a complete stopped-writer backup before an upgrade and keep it until the new runtime is accepted.

The macOS application requires macOS 13 Ventura or later on Apple silicon. Follow the [install and upgrade guide](https://github.com/BradGroux/veritas-kanban/blob/v6.2.0/docs/V6-UPGRADE-INSTALL-ADMIN-GUIDE.md) for the signed release. An unsigned local candidate is for verification and does not establish stable distribution readiness.

## Rollback

Restore the complete previous application bundle and, when needed, its matching stopped-writer backup. Do not mix bundled package versions. A System appearance preference is new in 6.2.0; select an explicit Light or Dark preference before returning to a version that does not support it.
