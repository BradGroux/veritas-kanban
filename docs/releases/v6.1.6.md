Veritas Kanban 6.1.6 is a focused desktop reliability and interface consistency release. It follows the larger 6.1.5 backlog release with fixes found while exercising the compiled macOS app.

## What changed

Board Chat and Squad Chat now remain contained inside the application shell instead of expanding the document and leaving a blank region below the app. Dragging cards uses the same bounded layout, and consecutive moves refresh task revisions so a second valid move no longer fails with a stale-conflict error.

The desktop header keeps the Veritas icon while removing the redundant product wordmark already shown by macOS. Settings has one aligned modal title and close control. Command+K now has clearer hierarchy, a prominent search field, a useful active-result summary, compact grouped results, and a brighter selected row.

Primary actions now share the same size and purple treatment across Templates, Workflows, Policies, Operations, Evidence, Time, and Drift pages. The active sidebar item uses that brighter purple with white icon and text, and the New Template button matches other page actions.

Maintained screenshots, desktop and mobile GIFs, social previews, and the demo video now show the 6.1.6 interface using only public-safe dummy data. The dependency graph also moves `qs`, `@xmldom/xmldom`, and `postcss-selector-parser` to patched releases; both production and complete dependency audits report no known vulnerabilities.

## Install or upgrade

Version 6.1.6 requires macOS 13 Ventura or later on Apple silicon. Back up the complete stopped-writer workspace before upgrading and retain the backup until the new runtime is accepted.

```bash
brew update
brew upgrade --cask bradgroux/tap/veritas-kanban
```

For a first installation:

```bash
brew install --cask bradgroux/tap/veritas-kanban
```

The Assets section provides signed and notarized macOS arm64 DMG and ZIP packages. Linux and Windows packages remain unsigned verification previews.

## Compatibility and rollback

The public REST API remains `v1`, and 6.1.6 adds no database migration. Valid 6.1.5 workspaces remain compatible. Roll back by reinstalling the complete 6.1.5 application bundle; do not mix package or bundled runtime versions.

See the [changelog](https://github.com/BradGroux/veritas-kanban/blob/v6.1.6/CHANGELOG.md) for issue and pull-request traceability.
