Veritas Kanban 6.1.5 publishes the integrated backlog completed after the 6.1.4 security patch. It includes the redesigned Settings and task workspaces, atomic board moves, clearer conflict recovery, accurate memory-pressure status, corrected chat toggles, Command+K and board-color improvements, reviewed dependency updates, and the public documentation boundary.

## What changed

Settings now groups all twenty destinations by workflow and uses one shared layout contract across every page. Task detail now centers Overview, Plan, Run, Results, and History around the task lifecycle, with one primary state and next action, progressive diagnostics, and an expanded workspace for dense review.

Cross-column moves persist status and order atomically and recover from partial failures. Conflict messages identify the affected task, action, revisions, and recovery path without suppressing distinct conflicts. Runtime health no longer mistakes ordinary V8 heap reservation for pressure, and simultaneous health probes use isolated storage checks.

Board Chat and Squad Chat header controls now close the active panel as well as open or switch it. Command+K has bounded layout, scrolling, denser results, complete keyboard navigation, and predictable focus restoration. Board color now communicates semantic identity without relying on generic edge highlighting.

The dependency set includes aligned immutable CodeQL action pins, reviewed compatible production updates, and Electron 44. Public documentation now excludes internal prompts, raw audits, handoffs, and working notes, with a CI guard that classifies every tracked Markdown file and validates local links.

Maintained screenshots, desktop and mobile GIFs, social previews, and the demo video now show the integrated 6.1.5 interface using only public-safe dummy data.

The native macOS About panel now presents a concise build identity, familiar Apple silicon naming, the project URL, and the MIT license alongside the copyright holder.

## Install or upgrade

Version 6.1.5 requires macOS 13 Ventura or later on Apple silicon. Back up the complete stopped-writer workspace before upgrading and retain the backup until the new runtime is accepted.

```bash
brew update
brew upgrade --cask bradgroux/tap/veritas-kanban
```

For a first installation:

```bash
brew install --cask bradgroux/tap/veritas-kanban
```

The Assets section provides signed and notarized macOS arm64 DMG and ZIP packages. Linux and Windows packages remain unsigned verification previews.

## Compatibility and rollback

The public REST API remains `v1`, and 6.1.5 adds no database migration. Valid 6.1.4 workspaces remain compatible. Roll back by reinstalling the complete 6.1.4 application bundle; do not mix package or bundled runtime versions.

The interface work changes Settings and task-workspace hierarchy and the named board interactions. It does not replace the existing Mantine and Tailwind component system or constitute an app-wide visual rebrand.

See the [changelog](https://github.com/BradGroux/veritas-kanban/blob/v6.1.5/CHANGELOG.md) for the complete issue and pull-request traceability.
