# Backlog implementation and release plan

Reviewed October 22, 2026. Baseline: `main` at `50b124ed2868e84509ee2be0cec5ed7de52fe2e0`, version 6.2.1. This is a proposed delivery sequence and live tracking document, not evidence that the listed fixes have shipped. The repository-wide audit remains tracked in [#1632](https://github.com/BradGroux/veritas-kanban/issues/1632); its children retain their complete acceptance criteria. This plan adds dependency maintenance, PR reconciliation, optional features, integration, documentation, and release delivery without replacing those issue contracts.

## Objective and completion boundary

Deliver the justified backlog in bounded changes, consolidate overlapping PR work, and finish with refreshed documentation, a version bump, and a release with full notes. The release scope includes optional ChatGPT identity sign-in and the accepted OrcaRouter integration. Do not enable either feature by default. The maintainer delegated the gateway-harness choice and authorized development of a local release/promotion path preserving signing, native, media, and provenance checks. The first gateway integration will target Codex CLI 0.155.1, the locally verified installed version, with conformance still required. The target release is 6.3.0, explicitly confirmed by the maintainer; keep version changes for the final release-preparation stage. Credential storage changes still require their own authorization.

Every implementation PR must address one independently shippable behavior. Shared code is a coordination relationship, not permission to combine unrelated acceptance criteria. Keep this tracking PR open until the final delivery evidence is linked. Merging a planning document does not complete the backlog.
